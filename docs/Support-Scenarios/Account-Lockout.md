# HD-002 Account Lockout

## Issue

User account locked after multiple failed login attempts.

## Investigation

- Located account in AD.
- Verified lockout status.
- Reviewed Account Lockout Policy.

## Resolution

- Unlocked account.
- Educated user regarding password requirements.

## Verification

- Successful domain login.

## Skills Demonstrated

- Active Directory
- Security Policy Management
- User Support
